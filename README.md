# expert-interview-minutes

把 AI 转录工具（通义 / 讯飞 / 豆包 / Paraformer 等）导出的专家访谈 docx，整理成两份可直接交付的 Word：**逐字稿汇总** + **纪要汇总**。

一个 Hermes Agent 技能（SKILL.md 格式）。核心不是"让 AI 总结"，而是把这件事做成**可复现的流水线**：模板版式照抄、指令链固定、专有名词逐条订正、页码用真实值。

## 它解决的问题

AI 转录稿直接交给大模型，通常会得到三种废稿：

1. **过度总结** —— 一小时的访谈压成十行结论，客户要的数字、公司名、判断依据全丢了；
2. **开始推测** —— 原文没说的话被"合理补全"，尽调材料里这是硬伤；
3. **版式不对** —— 满篇 Markdown 表格，和客户给的 Word 模板完全不是一回事。

这套流程用三步指令链把 ① ② 压住，用模板克隆把 ③ 解决，最后用「字符数零差异」验收。

## 流水线

```
转录 docx（会议摘要 + AI对话列表 + 原始对话列表）
  ├─ 删掉与 AI对话列表重复的「原始对话列表」
  ├─ 说话人映射：顾问→专家，咨询客户→采访者
  ├─ 逐句删填充词（啊/呃/呀/唉），保留真实口语
  └─ 专有名词订正（ASR 同音字是主要脏数据来源）
        ↓
  逐字稿（10pt，轮次间空行）
        ↓  三步指令链
  纪要（11pt，一、/ 1. / 分点三级，无表格）
        ↓
  模板克隆 + 目录 PAGEREF 回填 + 零差异验收
        ↓
  专家访谈逐字稿汇总.docx / 专家访谈纪要汇总.docx
```

## 三步指令链（关键）

不要合成一句，逐步追加效果明显更好：

1. `帮我根据逐字稿生成会议纪要，要求基本能够涵盖访谈中的全部内容，但不要过度总结推测生成访谈中没有的内容`
2. `再详细一点` —— 把被压成一句话的事实重新摊开（金额、公司名、判断依据、操作细节）
3. `把表格都弄成分点的形式，重新生成一版完整版，内容不变`

第 3 步必须做：模板里没有表格，而模型在"再详细一点"之后会大量输出表格。

## 文件

| 路径 | 内容 |

## 安装

```bash
git clone https://github.com/wukong22lzc/expert-interview-minutes.git \
  ~/.hermes/skills/consulting/expert-interview-minutes
```

装了 [Hermes Agent](https://github.com/NousResearch/Hermes-Agent) 的话，放到 `~/.hermes/skills/` 下即可按需加载；其他 agent（Claude Code / Codex CLI 等）可以直接把 `SKILL.md` 当工作手册用——里面的版式参数、验收标准和踩坑都是通用的。

## 适用与不适用

**适用**：硬科技 / 制造业尽调的专家访谈、专家网络电话、内部调研录音，一场 40 分钟到 2 小时、需要留痕的场合。

**不适用**：需要逐字法律取证的证词（要保留全部语气词和停顿）、多人圆桌（说话人分离会整段错位，需要人工先标）。

## 两个最容易踩的坑

- **说话人角色会整段错位。** 长音频里 AI 转录工具会大段翻转归属，出现"采访者：我觉得国内其实没有…"这种明显是专家在答的句子。按句式判断（疑问/引导=采访者，判断/自述=专家），按段块整体翻转，不要逐句翻。
- **标准名搜不到 ≠ 原文没有。** 同一个机构名在转写里可能有三四种同音写法，判"编造"之前先用全部变体各 grep 一遍。
