# 纪要生成指令链（DeepSeek 原样复用）

来源：用户分享的 chat.deepseek.com 会话（蓝河供应链.docx 示例）。三步走，**不要合并成一句**，逐步追加效果明显更好。

## 第 1 步：主指令

> 帮我根据逐字稿生成会议纪要，要求基本能够涵盖访谈中的全部内容，但不要过度总结推测生成访谈中没有的内容

## 第 2 步：加密

> 再详细一点

作用：把第 1 步里被压成一句话的事实重新摊开（具体金额、公司名、人名、判断依据、操作细节、合作案例）。仍严禁新增原文没有的内容。

## 第 3 步：去表格

> 把表格都弄成分点的形式，重新生成一版完整版，内容不变

作用：DeepSeek 在「再详细一点」之后会大量出表格（器件/交期、竞品对比、风险-应对）。成稿模板**没有表格**，全部要点化，所以必须在生成阶段就压掉。

## DeepSeek 输出骨架（拿到后要改成成稿格式）

DeepSeek 输出：

```
XX访谈纪要（详细版）

时间： 2026年3月26日
时长： 1小时37分29秒
受访人： 供应链负责人 龚总
访谈人： 内部调研团队（多人）

一、受访人背景与职责
1. 工作履历
- 2006-2008年：华虹NEC…
…
纪要整理人： 内部调研团队
日期： 2026年3月30日
```

成稿要求（差异清单，逐条执行）：

| DeepSeek 输出 | 成稿 |
|---|---|
| 标题＋时间/时长/受访人/访谈人 头部 | **全部删掉**，公司标题下面直接接「一、」 |
| 结尾「纪要整理人／日期」 | 删掉 |
| `1. 工作履历` 后接 `-` 短横列表 | `1.` 粗体小节 + 模板真实项目符号（`numPr` ilvl0），子项 ilvl1 |
| 表格 | 拆成分点，或「维度：值」单行 |
| Markdown `###`／`-` | 换成 `一、`／`1.`／项目符号三级 |
| 人名（龚总）／具体金额 | **保留**，这是「再详细一点」的价值所在 |

## 自己生成时等价指令

不走 DeepSeek 也行：把逐字稿全文给它，系统提示＝「你是纪要整理员，只做归纳不做推断；覆盖全部事实点、数字、判断、案例；禁止新增、禁止推测、禁止用会议摘要代替正文；输出三级结构：一、章节 / 1.小节 / 分点」。第 2、3 步的要求写进同一段提示词即可。
